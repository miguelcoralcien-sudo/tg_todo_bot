# Telegram-бот для хранения задач (Todo-бот)

Этот проект — Telegram-бот, написанный на Python с использованием библиотеки aiogram 3 и базы данных SQLite3. Бот создан для командной работы: он собирает идеи и задачи участников, сохраняет их в базу данных и по запросу выводит список.

## 🚀 Функционал (команды бота)
- /start — приветствие и краткая инструкция.
- /add — добавление новой задачи (бот переходит в режим ожидания текста).
- /list — вывод всех сохранённых задач с указанием ID, автора и даты.
- /list_csv — выгрузка всех задач в файл формата CSV и отправка его пользователю.

## 📂 Структура проекта
- main.py — точка входа, запуск бота и настройка диспетчера.
- handlers.py — обработчики команд (логика общения с пользователем, FSM).
- database.py — класс для работы с базой данных SQLite3 (создание таблиц, добавление, выборка, экспорт в CSV).
- .env.example — пример файла для токена.

## 🛠️ Установка и запуск

1. Создайте виртуальное окружение и активируйте его:
   python3 -m venv venv
   source venv/bin/activate

2. Установите зависимости:
   pip install aiogram python-dotenv

3. Создайте файл .env в корне проекта и добавьте туда токен от BotFather:
   BOT_TOKEN=ваш_токен_здесь

4. Запустите бота:
   python3 main.py

## ⚠️ Важно
Для работы бота требуется доступ к серверам Telegram (api.telegram.org). Если вы находитесь в регионе, где доступ ограничен, используйте VPN (в режиме TUN) или настройте прокси в терминале перед запуском.
